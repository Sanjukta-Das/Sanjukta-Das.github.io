Digit Classification

Recognized handwritten digits from MNIST Dataset by implementing perceptron learning algorithm. Trained 10 perceptron to learn and classify as a group, the handwritten digits in the MINST dataset, where each perceptron has 785 inputs consisting of 784 pixels i.e., 28x28 pixel image represented as gray scaled value (0 – 255) and one output i.e., either 0 or 1. Each perceptron’s target is one of the 10-digits (0-9) and it learns using the perceptron learning algorithm.
